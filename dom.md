# DOM Manipulation in JavaScript

DOM stands for Document Object Model. It represents the structure of an HTML document as a tree of objects.

## Why is DOM important?
DOM manipulation means using JavaScript to dynamically change the structure, content, and style of a web page:
- Change content
- Change styles
- Handle user events

## Selecting Elements:
JavaScript provides methods to select elements:

```js
document.getElementById("id");
document.getElementsByClassName("class");
document.querySelector(".class");
document.querySelectorAll("p");
